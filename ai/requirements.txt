# Runtime dependencies, pinned exactly. A range here would let a rebuild months
# from now resolve a different driver than the one this stack was verified
# against, on an image that is otherwise reproducible.
#
# psycopg 3, not psycopg2, and the [binary] extra rather than the pure-python
# build. The extra ships a wheel with libpq compiled in, which is what keeps this
# image free of `libpq-dev`, gcc and an apt layer -- there is no `apt-get` in
# ai/Dockerfile at all, and that is why.
#
# It is also the reason the base image is `python:3.12-slim` (glibc) rather than
# alpine: psycopg-binary publishes manylinux wheels and no musl ones, so alpine
# would fall back to building from source and need the toolchain this avoids.
psycopg[binary]==3.3.4
